# DOE aliasing, estimability, and efficiency diagnostics

Every non-Latin design generated by `scripts/doe_designs.py` includes a `design_diagnostics` block in JSON metadata (or stderr metadata for CSV). Review it before running the experiment.

## Reported fields

- `model`: the model matrix being audited.
- `rank` versus `n_parameters`: full equality is required for all listed coefficients to be separately estimable.
- `residual_df`: remaining degrees of freedom after the reported model rank. Zero residual degrees of freedom means pure error cannot be estimated without replication or additional assumptions.
- `condition_number`: numerical conditioning when the model is full rank; large values signal unstable coefficient estimation.
- `d_efficiency_percent`: determinant-based information index after factors are coded to roughly `[-1, 1]`. Compare designs only when they use the same model, factor coding, and run budget.
- `estimable_terms` and `non_estimable_terms`: coefficient-level row-space diagnostics for the displayed model.
- `warnings`: limitations such as ordered one-dimensional coding of multi-level or categorical factors.

For two-level full/fractional factorial designs, `alias_structure` additionally reports:

- `resolution`: shortest non-identity word in the defining relation; `null` for an unaliased full factorial;
- `groups`: complete effect-column alias groups, with a leading minus sign for negative aliasing.

The earlier compact `aliases` field is retained for compatibility, but `alias_structure.groups` is the authoritative machine-readable report.

## Interpretation rules

1. Name the effects the scientific question requires before choosing a fraction.
2. Reject a design when a required effect appears under `non_estimable_terms` or is aliased with another scientifically plausible effect.
3. Do not interpret resolution alone as design quality. Inspect the actual alias groups.
4. Response-surface designs are audited against a full quadratic model. Center replication supplies pure-error information but does not repair missing model rank.
5. The current multi-level/categorical diagnostic uses one ordered linear contrast per factor. Use a full contrast-coded model in dedicated DOE software when nominal factors have more than two levels.
6. D-efficiency is not comparable across different model formulas or codings, and it does not establish robustness to model misspecification.
