# A-MEM: Agentic Memory for LLM Agents

- **Citation**: Xu et al. (2025). arXiv:2502.12110. — `Xu et al. 2025`
- **DOI / arXiv**: arXiv:2502.12110
- **Read date**: 2026-07-28 | **Depth**: 精读
- **One-liner**: A memory system where the **LLM itself dynamically creates, links, and evolves note structures** — every new memory can spawn new attributes and link to past memories, producing an ever-growing self-organized knowledge graph.

## 1. Research question
Prior agent-memory systems use **fixed schemas** for memory entries (e.g., text + timestamp + embedding). Real-world knowledge does not have a fixed schema — a memory about "Project X was delayed because of vendor Y" needs a different structure than a memory about "User prefers coffee". Can an LLM **autonomously design the schema** for each memory, and link memories into a queryable structure?

## 2. Method (方法)
- **Atomic memory unit**: each new observation is converted into a structured note with LLM-generated attributes (context, keywords, tags) — the attribute set is **per-note**, not global.
- **Dynamic linking**: when a new note is created, the LLM is asked to identify related past notes and add links.
- **Evolution**: existing notes can be updated when new, related information arrives (the LLM decides to add / remove / re-attribute).
- **Retrieval**: hybrid — embedding similarity over the auto-generated attributes + structural traversal of the link graph.

**关键设计**：**the memory schema is a per-note output of the LLM**, not a fixed template. This is the structural innovation.

## 3. Contributions (创新点)
- **Claimed**: (1) agentic memory with dynamic note generation, (2) outperforms ChatGPT's built-in memory, (3) outperforms MemoryBank-style fixed-schema memory on LoCoMo benchmark.
- **Actual (my judgment)**: The dynamic-schema contribution is real and under-explored in the literature. The empirical results are encouraging but on a **single benchmark** (LoCoMo) — needs more.

## 4. Experimental setup (实验设置)
- **Data**: LoCoMo (long conversation benchmark), plus ablations on synthetic chat sequences.
- **Baselines**: full-prompt baseline, RAG, MemoryBank, LangMem.
- **Metrics**: F1, BLEU, LLM-judged answer quality.
- **Key results** (please verify):
  - A-MEM outperforms the strongest baseline by several points on LoCoMo. `[请人工核对]`
  - Ablation: removing dynamic linking or evolution hurts performance. `[请人工核对]`

## 5. Limitations (局限性)
- **Stated by authors**: schema generation adds LLM calls and latency; link quality is hard to evaluate; small-scale benchmarks.
- **My assessment**:
  - The dynamic-schema idea is interesting, but the **schema itself is opaque** — how do you know the LLM chose a good structure? This is a hard evaluation problem.
  - "Agentic memory" is partly a marketing term; the mechanism is closer to a self-organizing knowledge graph.
  - No analysis of compute cost — dynamic schema generation is expensive.

## 6. Reusable resources
- **Code**: <https://github.com/WujiangXu/A-mem> `[not verified from PDF]`
- **Reusable ideas**: the **dynamic per-note attribute generation** pattern is the most importable. It decouples memory from any fixed schema.

## 7. Connections
- Builds on the **declarative-memory** tradition ([Park et al. 2023, Generative Agents]; [Zhong et al. 2024, MemoryBank]) but lifts the schema constraint.
- A practical implementation of the **declarative + conditional** memory cell in [Sumers et al. 2024, CoALA].
- Complementary to [Packer et al. 2023, MemGPT] — MemGPT paginates, A-MEM organizes.
